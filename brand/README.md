# شعار تطبيق الأناقة الذكي

الشعار **ثابت ورسمي**: لا يُعاد رسمه ولا تُغيَّر ألوانه أو نسبه. كل الأحجام تُولَّد من ملفات SVG في هذا المجلد.

**الفكرة:** علّاقة ملابس (المحل والكاشير) خطّافها سهما مزامنة (التطبيق يعمل بدون إنترنت ويتزامن مع السيرفر والمتجر الإلكتروني)، والنجمة تعني "الذكي".

| اللون | الكود |
|---|---|
| كحلي | `#1B2A5C` |
| ذهبي | `#C9A24A` |
| ذهبي فاتح (النجمة) | `#E3C77E` |
| كريمي | `#F7F1E6` |

الخطوط: Cairo ExtraBold (عربي)، Poppins Bold (إنجليزي). النصوص في ملفات SVG محوّلة لأشكال.

| الملف | الاستخدام |
|---|---|
| `icon.svg` | الأيقونة: القائمة الجانبية، ترويسة الجوال، أيقونة المتصفح |
| `favicon-32.png` / `apple-touch-icon.png` / `icon-192.png` | أيقونة المتصفح والشاشة الرئيسية |
| `logo-stacked-transparent.svg` | الشعار مع الاسم بدون خلفية (شاشة الدخول) |
| `logo-horizontal.svg` | الشعار الأفقي على خلفية كريمية |
| `mark-gold.svg` | الرمز وحده بدون خلفية |

المصدر الكامل لكل الأشكال (iOS وأندرويد والنسخ الداكنة) في مستودع التطبيق: `Clothing-store_App/brand/`.
